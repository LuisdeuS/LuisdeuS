## Projects

**Platanus Build Night — Autonomous Registration Agent**

CLI-based autonomous agent that navigates a multi-step API registration protocol without human intervention.

- Deterministic state machine for data collection; LLM reasoning isolated exclusively to the challenge-resolution step
- Typed API contracts with Zod, structured observability via `run.log`, retry resilience on challenge verification
- No frameworks — native Anthropic/Gemini SDK + Bun runtime

Tech: TypeScript, Bun, Gemini 3.1 Pro, Zod, Chalk, Ora

**Club VIP (private enterprise)**

Full-stack membership management platform for a corporate VIP loyalty program,
built in collaboration with a partner.

- Admin dashboard with role-based access control and CSV bulk-import
  for simultaneous registration of clients, distributors, and zones
- Email invitation system via Nodemailer with HTTPS server and
  self-signed certificate support
- Vanilla JS/HTML/CSS client — zero frontend dependencies

Tech: TypeScript, Node.js, PostgreSQL, PL/pgSQL, HTML, CSS, JavaScript
